# 👗 StyleHub - Fashion E-Commerce Website

StyleHub is a modern, responsive fashion e-commerce website built using **HTML, CSS, and JavaScript**. It provides a clean user interface with product browsing, search, filtering, shopping cart functionality, wishlist, dark mode, and responsive design.

---

## 📌 Project Overview

StyleHub is designed to provide users with an engaging online shopping experience. The website allows customers to browse fashion products, search items, filter by category, add products to a shopping cart, and manage their wishlist.

---

## 🚀 Features

- 🏠 Responsive Home Page
- 👕 Product Categories
- 🛍️ Featured Products
- 🔍 Product Search
- 🎯 Product Category Filter
- ❤️ Wishlist Feature
- 🛒 Shopping Cart
- ➕ Add to Cart
- ❌ Remove Items from Cart
- 💰 Total Price Calculation
- 💳 Checkout Button
- ⭐ Product Ratings
- 🌙 Dark Mode
- 🔝 Back-to-Top Button
- 📧 Newsletter Subscription
- 📞 Contact Form
- 📱 Mobile-Friendly Design
- 🍔 Responsive Hamburger Menu

## ⚙️ Installation

1. Download or clone this repository.

```
git clone https://github.com/Ramzeena-s/stylehub.git
```

2. Open the project folder.

3. Open `index.html` in your browser or run it using **Live Server** in Visual Studio Code.

---

## 💻 How to Use

- Browse fashion products.
- Search products using the search bar.
- Filter products by category.
- Add products to the shopping cart.
- Remove products from the cart.
- Add products to your wishlist.
- Toggle between Light Mode and Dark Mode.
- Scroll using the Back-to-Top button.
- Proceed to checkout.
